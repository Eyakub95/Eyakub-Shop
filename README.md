# EyakubShop – GitHub Pages ই-কমার্স ওয়েবসাইট

সম্পূর্ণ ফ্রি, কোনো সার্ভার বা ডেটাবেস ছাড়াই চলে।

## ফাইলের তালিকা
| ফাইল | কাজ |
|---|---|
| `index.html` | মূল দোকানের পেজ |
| `style.css` | ডিজাইন ও রঙ |
| `app.js` | কার্ট, সার্চ, চেকআউট, অর্ডার |
| `products.js` | **আপনার দোকানের সেটিংস, ক্যাটাগরি ও সব পণ্য** |
| `admin.html` | নতুন পণ্যের কোড বানানোর টুল (`আপনার-সাইট/admin.html`) |
| `images/` | নিজের পণ্যের ছবি রাখার ফোল্ডার |

## ১. GitHub-এ আপলোড (ধাপে ধাপে)
1. https://github.com এ লগইন করুন।
2. ওপরে ডানে **+ → New repository** চাপুন।
3. Repository name দিন: `EyakubShop` (Public রাখুন) → **Create repository**।
4. **uploading an existing file** লিংকে চাপুন।
5. zip খুলে ভিতরের **সব ফাইল ও images ফোল্ডার** টেনে এনে ছেড়ে দিন (zip নিজে নয়, ভিতরের ফাইলগুলো)।
6. নিচে **Commit changes** চাপুন।
7. **Settings → Pages** এ যান → Source: **Deploy from a branch** → Branch: **main**, Folder: **/ (root)** → **Save**।
8. ১–৩ মিনিট পর সাইট চালু হবে: `https://আপনার-ইউজারনেম.github.io/EyakubShop/`

## ২. প্রথমেই যা বদলাবেন (`products.js` এর শুরুতে)
```js
whatsapp: "8801XXXXXXXXX",  // আপনার হোয়াটসঅ্যাপ নম্বর (88 দিয়ে শুরু, + ছাড়া)
phone: "01XXXXXXXXX",
facebook: "আপনার ফেসবুক পেজের লিংক",
```
**হোয়াটসঅ্যাপ নম্বর না বদলালে অর্ডার আপনার কাছে আসবে না।**

## ৩. নতুন পণ্য যোগ
1. `আপনার-সাইট/admin.html` খুলুন, ফর্ম পূরণ করুন, কোড কপি করুন।
2. GitHub-এ `products.js` খুলে ✏️ (Edit) চাপুন।
3. `const PRODUCTS = [` লাইনের ঠিক নিচে কোড পেস্ট করুন → **Commit changes**।

## ৪. নিজের ছবি ব্যবহার
`images` ফোল্ডারে ছবি আপলোড করুন (ছোট সাইজ, ৫০০×৫০০, ১৫০ KB এর নিচে ভালো), তারপর `products.js` এ `image: "images/ফাইলের-নাম.jpg"` লিখুন।

## ৫. কীভাবে অর্ডার আসে
গ্রাহক কার্টে পণ্য দিয়ে চেকআউট করলে অর্ডারের পূর্ণ বিবরণসহ **আপনার হোয়াটসঅ্যাপে মেসেজ** তৈরি হয়ে যায়। আপনি কল করে কনফার্ম করে কুরিয়ারে পাঠাবেন।

## ৬. সীমাবদ্ধতা (গুরুত্বপূর্ণ)
GitHub Pages শুধু স্ট্যাটিক হোস্টিং। তাই এখানে নিচের জিনিস **নেই**:
- অনলাইন পেমেন্ট (bKash/Nagad গেটওয়ে), ইউজার লগইন, সেলার প্যানেল, রিয়েল-টাইম স্টক আপডেট
- অর্ডার ডেটাবেসে জমা হয় না (হোয়াটসঅ্যাপই অর্ডারের রেকর্ড)

পরে বড় করতে চাইলে ফ্রি অপশন: **Firebase** বা **Supabase** (লগইন + ডেটাবেস), **Netlify Forms** (অর্ডার ফর্ম)। এগুলো এই সাইটের সাথেই জোড়া যায়।

## ৭. কাস্টম ডোমেইন (ঐচ্ছিক, টাকা লাগবে)
`eyakubshop.com` কিনলে Settings → Pages → Custom domain এ বসিয়ে দিলেই হবে।
